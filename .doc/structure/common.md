# Common Utilities (com.hypixel.hytale.common)

## Subpackages
- **benchmark** — benchmarking helpers.
- **collection** — custom collections.
- **fastutil** — fastutil integrations/adapters.
- **map** — map utilities.
- **plugin** — plugin metadata types (`PluginManifest`, `PluginIdentifier`, `AuthorInfo`).
- **semver** — semantic versioning (`Semver`, `SemverRange`).
- **thread** — thread factories and helpers.
- **tuple** — tuple types.
- **util** — common utility classes (formatting, hardware, network, manifest helpers).

These utilities are used throughout server and plugin code.
