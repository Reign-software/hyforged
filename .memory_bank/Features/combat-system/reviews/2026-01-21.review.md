### Major (blocking) — All Resolved
- [x] Crit is not guaranteed to be rolled once per attack for multi-element damage events. **RESOLVED:** Added `PIPELINE_PROCESSED` meta key. Damage events dispatched by `CombatService` are marked as already processed, and ECS systems (`HyforgedHitResolutionSystem`, `HyforgedAutoBlockSystem`, `HyforgedCriticalHitSystem`, `HyforgedDamageReductionSystem`) skip processing for events with this flag. Also, `CRIT_ROLLED` meta key is set on dispatched events to ensure cohesion.
- [x] CombatService applyDamage computes the full combat pipeline and then dispatches Damage events into the same pipeline without a skip mechanism, which can re-apply evasion, block, resistance, and crit. **RESOLVED:** Added `CombatMeta.PIPELINE_PROCESSED` flag set by `CombatServiceImpl` before dispatching. All four ECS damage systems now check this flag and skip processing if set.

### Minor (non-blocking)
- [ ] Combat log UI (HUD/command) not validated in-game; manual verification is still required to confirm the acceptance criterion for player-visible combat logs.

## Required Actions (Critical/Major)
