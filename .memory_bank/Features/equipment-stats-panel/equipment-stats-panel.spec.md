# Feature Spec: Equipment Panel on Character Stats Page

## Metadata
- Feature ID (slug): equipment-stats-panel
- Status: Approved
- Owner: Hyforged Team
- Date: 2026-02-19

## Summary
Enhance the Character Stats page with a visual equipment panel on the left side showing item icons (via single-slot ItemGrid elements) for all 6 equipped slots (armor 0–3, hand 0–1), with rich hover tooltips displaying item name, quality, and affixes. Remove the Range column from the stats table, moving range info into the stat name tooltip, and widen the page to ~1120px.

## Goals
- Give players an at-a-glance view of their equipped gear directly on the Character Stats page
- Surface item quality and affix details via hover tooltips, reusing existing tooltip infrastructure
- Reduce visual clutter in the stats table by relocating range data into the stat description tooltip
- Maintain data-driven, localized, and performant UI patterns

## Non-Goals
- Drag-and-drop equipment management (this page is read-only display)
- 3D model previews or animated equipment renders
- Changing the underlying inventory or affix systems
- Adding new equipment slot types beyond what Hytale currently supports
- Equipment comparison tooltips (e.g., "what if I equipped this other item")
- Collapsible or hideable equipment panel

## User Experience

### Opening the page
- Player opens Character Stats via `/hyforged character`, the Ability1 keybind when unarmed, or programmatic API — no change to access methods.

### Equipment panel (left side)
- A vertical equipment panel appears to the LEFT of the stats table, always visible (not collapsible).
- All 6 equipment slots are always displayed: Head, Chest, Legs, Feet, Main Hand, Off Hand.
- Each slot shows the equipped item's icon via a 1-slot ItemGrid element. Empty slots display a localized "Empty" indicator.
- If ItemGrid rendering fails in custom pages, a text-based fallback displays the item name colored by quality tier.

### Hover tooltip on equipment slot
- Hovering over an equipped item shows a fixed-position tooltip overlay containing:
  1. **Item name** — colored by quality tier
  2. **Quality label** — e.g., "[Rare]" colored by quality tier
  3. **Affix lines** — generated via existing tooltip infrastructure, showing section headers and per-line stat colors
- Hovering over an empty slot shows no tooltip.
- Only one equipment tooltip is visible at a time.

### Stats table changes
- The "Range" column is removed from the table.
- The stat name hover tooltip is enhanced to include the stat's min/max range when meaningful.
- Column widths are redistributed to use the freed horizontal space.

### Page width
- The overall page width increases to ~1120px to accommodate the equipment panel without shrinking the stats table.

## Functional Requirements

### FR-1: Equipment Panel Layout
- A new panel is added to the LEFT of the existing stats content area.
- The panel has a localized title header.
- The panel contains 6 slot positions (4 armor + 2 hand), always visible, arranged vertically.
- Each slot displays a localized slot-type label (Head, Chest, Legs, Feet, Main Hand, Off Hand).

### FR-2: Equipment Slot Item Display
- Each slot uses a 1-slot ItemGrid element populated via the ItemGridSlot API to render the equipped item's icon.
- Empty slots display a distinct empty-slot visual indicator with localized "Empty" text.
- Text-based fallback (quality-colored item name in a Label) is used if ItemGrid rendering does not work in custom pages.

### FR-3: Equipment Tooltip — Item Name with Quality Color
- On hover, the tooltip displays the item's display name colored by its quality tier.
- Quality color is obtained from the quality asset system's text color.

### FR-4: Equipment Tooltip — Quality Label
- The tooltip includes a quality label line (e.g., "[Rare]") colored by the quality tier.

### FR-5: Equipment Tooltip — Affix Lines
- The tooltip includes affix information generated by the existing tooltip provider.
- Affix sections (Prefixes, Suffixes, Forged) display with section headers and per-line stat colors, matching the weapon-swap HUD tooltip style.
- If the item has no affixes, the affix section is omitted.

### FR-6: Equipment Tooltip Interaction
- The tooltip appears on MouseEntered over the slot container Group and disappears on MouseExited.
- Only one equipment tooltip is visible at a time.
- The tooltip is a fixed-position overlay near the equipment panel, not overlapping the stats table.
- Tooltip content is pre-built per slot during page build and cached in a map keyed by slot identifier.

### FR-7: Remove Range Column from Stats Table
- The Range column header is removed from the column headers row.
- The Range value label is removed from the stat row template.
- The Java code no longer sets range values per row.

### FR-8: Range Info in Stat Name Tooltip
- The stat name tooltip is enhanced to append the stat's min/max range when the range is meaningful (not both bounds unbounded).
- Uses the existing range formatting logic already present in the page.

### FR-9: Page Width Increase
- The root page anchor width increases to ~1120px (from 900px).
- The stats table area retains its current effective content width.

### FR-10: Remove Legacy Text-Based Equipment Section
- The existing text-only equipment section at the bottom of the scroll area is removed, replaced by the new icon-based equipment panel.

### FR-11: Column Width Redistribution
- With the Range column removed, remaining columns (Stat, Base, Modifier, Effective) redistribute widths to use available space.
- Column header alignment remains consistent with row data alignment.

## Non-Functional Requirements

### NFR-1: Performance
- Equipment panel data (icons, quality, affixes) is gathered once during page build and cached.
- Tooltip content is pre-built for all 6 slots during build (overhead is negligible — under 5ms for 6 items).
- No per-tick or per-frame computation; all updates happen on page open or explicit refresh.
- Target: <50ms additional overhead for equipment panel at page open.

### NFR-2: Data-Driven
- Slot labels, tooltip formats, and all display text use translation keys — no hard-coded user-facing strings.
- Quality colors come from the Hytale ItemQuality asset system, not hard-coded color maps.

### NFR-3: Localization
- New translation keys for: equipment panel title, slot-type labels (head, chest, legs, feet, main hand, off hand), empty slot text, range label for enhanced stat tooltip.
- All keys added to the language file with the project's prefix convention.
- No Unicode characters in any user-facing text.

### NFR-4: Consistency
- Equipment tooltip visual style matches the existing weapon-swap HUD tooltip pattern.
- Stat name tooltip enhanced format is consistent with the existing modifier tooltip style.

### NFR-5: Maintainability
- Equipment panel and tooltip logic is separated into clearly defined methods, not embedded monolithically in build().
- Reuses existing tooltip generation and quality resolution services — no duplication.

## Dependencies
- **AffixTooltipProvider** — generates structured tooltip content from item data
- **HyforgedQualityService** — resolves effective quality for items
- **ItemQuality** (Hytale API) — provides quality text colors
- **HyforgedItemDataService** — reads item metadata for affix data
- **Player inventory API** — armor and hotbar containers
- **Hytale UI system** — InteractiveCustomUIPage, UICommandBuilder, UIEventBuilder, CustomUIEventBindingType, ItemGrid, ItemGridSlot
- **StatDefinition** — provides min/max values, description, display format for enhanced tooltips
- **Existing CharacterStatsPage** — this feature modifies the existing page

## Data/Schema Impact
- No database or persistent data changes.
- UI layout files modified: CharacterStatsPage.ui, CharacterStatRow.ui.
- New UI template file possible for equipment slot rendering (or built inline via appendInline).
- Language file additions for new translation keys.
- PageEventData codec reuses existing Action + TooltipTarget keys with new action values for equipment tooltip show/hide.

## API Changes
- No public API changes. Internal refactoring of CharacterStatsPage only.

## Security/Privacy
- N/A — server-side only, no player data exposed. Equipment data is the player's own inventory.

## Observability
- No additional logging or metrics required beyond existing page lifecycle logging.

## Risks
- **Medium — ItemGrid rendering in custom pages**: ItemGrid + ItemGridSlot is the proven API pattern, but has not been tested specifically in Hyforged custom InteractiveCustomUIPages. Mitigated by a spike test before full implementation and a text-based fallback (quality-colored item names) if rendering fails.
- **Low — Page width at ~1120px**: May clip on very small resolutions. Mitigated by the fact that built-in Hytale inventory pages are larger, and 1120px is well under standard 1920px.
- **Low — Tooltip positioning**: Equipment tooltips use a fixed-position overlay (same pattern as existing modifier tooltip). No dynamic positioning needed.
- **Low — Event binding count**: 12 new bindings (6 MouseEntered + 6 MouseExited) is trivial; PassiveTreePage handles 150+ without issues.

## Open Questions
- None. All previously open questions have been resolved:
  - Item icons: Use ItemGrid single-slot pattern with text-based fallback.
  - Off-hand slot: All 6 slots always visible.
  - Collapsible: Not collapsible, always visible.
